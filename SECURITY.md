# Security policy

Report a vulnerability privately through [the repository’s Security tab](https://github.com/arpan-mandal/moving/security) using **Report a vulnerability**. Include the affected version, impact, and steps to reproduce. Use a generated or anonymized sample if the report involves a media file. Public issues are for ordinary bugs and support requests.

Moving uses read-only, user-selected file access and app-scoped bookmarks. Reports involving sandbox access, file handling, or packaging are especially useful when they include the exact macOS version and whether the app was built locally or downloaded from a release.
